# RainyDays Course Assignment

RainyDays is a responsive e-commerce website for outdoor rain jackets.
The project was designed in Figma and developed using HTML and CSS as part of a front-end development assignment.

## Features

- Responsive design for desktop, tablet and mobile
- Homepage
- Women's and men's jacket as product listing page
- Product details page
- Shopping cart
- Checkout page
- Order confirmation page
- Coming soon page for interactive features
- Accessible forms and semantic HTML structure

## Built With

- HTML
- CSS
- Figma
- GitHub Pages
